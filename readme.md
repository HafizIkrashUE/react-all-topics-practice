## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/HafizIkrashUE/react-all-topics-practice.git
````

Go to the repository:

```bash
cd react-all-topics-practice
```

Since each project is a separate React/Vite project, go inside the project you want to run.

For example:

```bash
cd 11reduxToolkitTodo
```

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

You can follow the same process for any other project folder.
